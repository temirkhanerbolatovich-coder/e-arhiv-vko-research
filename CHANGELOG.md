# Changelog

## 2026-11-12 — Публикация архивного редизайна

- Текущий редизайн разрешён пользователем к публикации через GitHub и Vercel.
- Обновлены эмблема и название, орнамент, закреплённый поиск и тёмный подвал; сохранена информационная концепция.
- Добавлены диалог фильтров, обновлённые новости, выставки, контакты и состояния ошибок.
- Панель получила локальные редакторы записей, публикаций и переводов, очередь файлов и JSON-выгрузки. Эти новые действия не меняют БД.
- Подготовлена публичная гостевая книга с отдельно обозначенным образцом ленты; действующая отправка обратной связи сохранена.
- Для двух подразделений доступны снимки с источниками; остальные фотографии и разрешения требуют дальнейшей сверки.
- Серверный код, база и конфигурация отключённой модели не изменены.

## 2026-11-12 — Репозиторий для жюри и стенд владельца

- В `main` объединены ранее опубликованные исходники и документы с сохранением истории разработки.
- Обновлены главная страница репозитория, индекс документации и различия между проектной и реализованной БД.
- Добавлены маршрут просмотра для жюри, инструкция Vercel и отчёт о проверке стенда.
- Стенд владельца: [e-arhiv-vko-portal.vercel.app](https://e-arhiv-vko-portal.vercel.app/), production из `main`.
- Новый локальный редизайн не входит в эту публикацию.

## 2026-11-11 — Оформление и голос

- Единый слой `frontend/theme.css`: главный экран на архивной фотографии Усть-Каменогорска, заголовки шрифтом Literata, крупный текст, одна карточка и одна кнопка на весь сайт, тёмный подвал.
- Главная: «Машина времени» (фото по десятилетиям, счёт совпадает с каталогом) и «Памятные даты» из календаря архива.
- Голос: «Сказать» в поле вопроса и «Прослушать» у ответа помощника.
- Знак помощника «Сандық» вместо искры.
- Адрес демо-стенда: https://e-arhiv-vko.vercel.app

## 2026-11-11 — Бэкенд, ИИ-помощник и демо-стенд

- `backend/`: API `/api/v1` (Hono, TypeScript), PostgreSQL/PGlite с pgvector и pg_trgm, гибридный поиск (шифр, полнотекстовый ru/kk, смысловой, триграммы, исторические названия мест).
- Каталог собран из данных репозитория: 1551 фонд с историей названий, 1109 газет, 1048 фотографий, 1634 страницы, 169 новостей, 201 памятная дата, 14 подразделений с координатами (OSM, требуют подтверждения архивом).
- ИИ-помощник на GPT-6 Luna: ответы только по найденным материалам с карточками-источниками, фильтрами и ссылкой в каталог; маскирование ИИН/телефонов/почты; запасной режим поиска без модели.
- Панель сотрудника: вход, 7 ролей, модерация со статусами и журналом, черновик карточки с ИИ-распознаванием скана, импорт/экспорт CSV, модерация отзывов, ИИ-аналитика по обезличенной статистике.
- Фронтенд подключён к API с откатом на локальные примеры; новая карточка материала `#/resource/{id}`; карта и «ближайший филиал» на странице филиалов.
- Тесты `backend/test`, CI, сборка для Vercel (`npm run build:vercel`).
