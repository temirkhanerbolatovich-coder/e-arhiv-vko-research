# Набор данных для разработчиков

Экспорт из сохранённых материалов архива, без обращения к сайту. Это снимок состояния, а не API и не доказательство полноты сайта. В `manifest.json` указаны время экспорта, размеры и SHA-256 выгрузок, количества и ошибки. Все пути внутри записей отсчитываются от корня папки `e-arhiv-vko-research` в полном архиве.

## Файлы

Файлы `.jsonl` — UTF-8, один JSON-объект на строку; переносы внутри строк экранированы. `items.csv` — UTF-8 с BOM, с заголовком; читается Excel и большинством библиотек CSV.

| Файл | Описание и ключевые поля |
| --- | --- |
| `pages.jsonl` | По одному объекту на каждый обнаруженный URL типа «страница»: `url`, `status`, `http_status`, `error`, `visited_at`, `title`, `language`, `discovered_from`, `page_json`, `html`, `markdown`, `text`, `headings`, `tables`. При недоступности исходного файла поле `export_error` объясняет проблему. |
| `files.jsonl` | По одному объекту на обнаруженный URL файла: `url`, `status`, `http_status`, `error`, `visited_at`, `name`, `discovered_from`, `local_path`, `byte_size`, `sha256`, `mime_type`, `duplicate_of`. `duplicate_of` — путь к уже сохранённому файлу, а не адрес URL. При ошибке выгрузки указан `export_error`. |
| `links.jsonl` | Каждая обнаруженная ссылка: `source`, `target`, текст `text`, исходная классификация `link_status`, а также `target_status` и `target_kind` из очереди, если цель в неё включена. Внешние и исключённые ссылки могут не иметь состояния цели. |
| `items.csv` | Плоский индекс всех страниц и файлов, включая неудачные и ожидающие обработки, с исходными названиями полей SQLite. |
| `comment_occurrences.jsonl` | Все извлечённые появления записей гостевой книги; `identity`, текст, автор, контактная ссылка и `source` с URL, языком, номером страницы, позицией и путями к оригиналам. Это появления, а не обязательно самостоятельные отзывы. |
| `manifest.json` | Версия схемы, UTC-время, количество строк, ошибки, контрольные суммы результатов и метаданные исходной выгрузки комментариев. |

`ok` означает успешно сохранённый ответ; `failed` — ошибка, `pending` — адрес не обработан, `excluded` — исключён по ограничению, `redirect` — переадресация. Конкретные причины и HTTP-коды отражены в записи и `logs/crawl.log`. Время посещения сохраняется как строка с часовым поясом; пустые или отсутствующие значения не следует считать датой, нулевой ошибкой или подтверждением отсутствия данных. `discovered_from` — одна из страниц обнаружения; все известные связи представлены в `links.jsonl`.

Выгруженный текст страниц взят из уже сохранённого JSON и может содержать меню и другие повторяющиеся элементы. Данные таблиц, OCR и исходные документы находятся в других каталогах; ссылки на таблицы и оригиналы приведены в записях. Если в отдельном GitHub-репозитории нет `pages/` или `downloads/`, распакуйте все части релиза в общую папку и используйте пути относительно её корня.

Каталог фотографий и альбомов находится отдельно в [`../gallery/`](../gallery/README.md): CSV и JSON содержат подписи, идентификаторы и ссылки на сохранённые страницы; исходные фото отдельными запросами не скачивались. CSV из сайта содержит произвольный текст, который может начинаться с символов формул. Для программной обработки предпочтителен JSON; при импорте в таблицы задавайте поля как текст и не выполняйте формулы.

## Пример Python

```python
import json
from pathlib import Path

root = Path('e-arhiv-vko-research')
with (root / 'datasets/developer/pages.jsonl').open(encoding='utf-8') as source:
    for line in source:
        page = json.loads(line)
        if page['status'] == 'ok' and page['language'] == 'ru':
            print(page['title'], page['url'])
```

## Обновление

Дождитесь остановки сборщика. Из корня архива выполните:

```powershell
python -m pip install -r requirements.txt
python extract_guestbook.py
python export_developer_data.py
```

Экспортёр читает очередь и связи в одной транзакции SQLite, копирует выгрузку комментариев и не меняет исходники. Перед запуском сначала сформируйте актуальные комментарии, иначе они будут относиться к более раннему снимку. Код завершения `1` и поле `errors` в манифесте означают, что некоторые исходные файлы или выгрузка комментариев отсутствуют либо повреждены. Скрипт не проверяет SHA-256 каждого оригинала: это выполняет `python report.py`.

## Доступ и обработка

Комментарии и страницы могут содержать имена, адреса электронной почты и другие персональные данные. Сохраняйте набор в закрытом репозитории и ограничивайте передачу. HTML и текст сайта — недоверенный ввод: экранируйте содержимое при отображении и не исполняйте скрипты из исходных страниц. В HTML встречаются формы и служебные поля; их сохранение не даёт разрешения отправлять формы или обходить ограничения сайта.
