# Фотогалерея

Эти файлы содержат каталог альбомов и подписей, обнаруженный в сохранённой русской версии страницы `/ru/SiteGallery`. Список альбомов находился в HTML в элементах `div.list-item[data-id]`; соответствующие страницы альбомов получены основным обходом сайта. Исходные страницы и время сохранения указаны в `albums.json` и `albums.csv`.

На каждой странице альбома сайт содержит HTML-шаблон `script#gallery-photos-src`; `photos.csv` и `photos.json` содержат номер альбома, номер фото, подпись, позицию, относительный URL миниатюры и путь к сохранённой странице-источнику. Полученные ID отражают элементы сайта, но не являются гарантией глобальной уникальности в других наборах.

Восстановить индекс из уже сохранённых страниц: `python extract_gallery.py` из корня архива. Скрипт использует `requests` и `beautifulsoup4` из `requirements.txt`. В обычном режиме сетевых запросов нет. Доступный вариант `--fetch` обращается только к страницам альбомов, отсутствующим локально; его нельзя запускать параллельно с основным обходом. URL собираются только из ID сохранённой страницы списка; задержка и ограничение числа повторов предусмотрены.

Фото и их полные описания отдельными запросами не загружались; `thumbnail_url_as_listed` записан из сайта и может относиться к уменьшенному изображению. Иные не перечисленные альбомы и возможные обновления после даты исследования не охвачены. Статусы и ошибки обработки перечислены в `albums.csv` и `summary.json`. Подписи передают исходные данные, точность которых независимо не проверена.

CSV сохраняет текст без изменения; некоторые подписи начинаются с символов, которые табличные программы могут интерпретировать как формулы. Для программной обработки предпочтителен JSON; при открытии CSV импортируйте поля как текст и не выполняйте формулы из содержимого сайта.
