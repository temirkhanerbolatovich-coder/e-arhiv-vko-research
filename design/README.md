# Дизайн: макет «Сандық» (предложение)

Статус: **предложение команды, не утверждено заказчиком**. Лежит в отдельной ветке `design/mockup-v1` и в `main` не попадает до решения команды: в [AGENTS.md](../AGENTS.md) сказано, что дизайн пока не утверждён.

| Файл | Что внутри |
|---|---|
| [Sandyq_maket.pdf](Sandyq_maket.pdf) | Макет всего сайта: 17 слайдов, каждый экран в двух вариантах (desktop 1440 и mobile 390). Логотип, главная, ответ помощника (пример из ТЗ 5.8 Б), каталог, карточка документа, поиск фонда организации, карта филиалов, выставка, «Большой архив памяти», справка о шифре, тёмная тема на казахском, админка (модерация, «скан → карточка», ИИ-аналитика), дизайн-система |
| [DESIGN.md](DESIGN.md) | Дизайн-токены: логотип, цвета светлой и тёмной темы, типографика, отступы, скругления, глубина, движение, компоненты |

Источники данных в макете:
- фотографии взяты из публичной фотогалереи текущего сайта ГА ВКО;
- фонды (Р-1, Р-136, Р-451, Р-186, Р-1008, Р-354) взяты из `datasets/structured_data/funds_2018.csv`;
- контакты филиалов взяты из выгруженных страниц сайта.

Что не из реальных данных:
- шифр в карточке документа помечен «демо»;
- цифры в админке — демонстрационные;
- казахские тексты черновые и требуют вычитки носителем.
