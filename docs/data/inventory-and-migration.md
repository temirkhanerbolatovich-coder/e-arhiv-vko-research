## Сопоставление с новой моделью

| Исходные данные | Целевые сущности | Обязательная проверка |
|---|---|---|
| Информационные страницы | pages + resource_versions | Удалить меню/формы/скрипты из тела, определить язык и тип |
| Контакты и филиалы | branches, branch_contacts, branch_hours | Текущее название/подчинение, адрес, координаты, расписание |
| Каталоги фондов | funds, fund_names | Повтор номера может описывать историю одного фонда; не создавать дубль |
| Газетные перечни | periodical_titles, periodical_holdings | Издатель, место, период, тома, примечания; не создавать выдуманное дело |
| Новости | news + версии | Дата публикации отдельно от даты исторического события |
| Альбомы/подписи | collections + импортные кандидаты | Нет полученного изображения — нет files с фиктивным storage_key |
| PDF/изображения/офисные файлы | files, resource_files, source_records | Реально полученный файл, SHA, тип, вредоносный контент, права |
| Гостевая книга | Кандидаты feedback | Повторы, личные сведения, разрешённость повторной публикации; автоматически не публиковать |
| Старые страницы и URL | source_records, legacy_redirects | Назначение и новый канонический маршрут, без открытого редиректа |

## Нюансы, обнаруженные в образцах

В `funds_2018.csv` номер «Р-1 ч.с.» встречается с названиями разных периодов. Пара `branch_id + number` определяет фонд только после проверки филиала и нормализации. Исходные номера сохраняются, объединение по одному заголовку запрещено.

Даты первого поступления и заполнения карточки могут быть числами Excel. Их нельзя трактовать как год: учитывать систему дат исходной книги и сохранять исходное значение. Поля вроде «3618/34с» нельзя без объяснения превращать в одно число. Объединённые ячейки и формулы CSV не восстанавливает.

## Процесс импорта

1. Зарегистрировать источник и контрольную сумму в source_records, создать import_batch с версией правил.
2. Сохранить сырые строки и их позицию в import_rows. Доступ к этому слою — только сотрудникам.
3. Предложить тип материала, сопоставление филиала, языка, дат и реквизитов. Неизвестное оставить NULL/needs_review.
4. Найти кандидатов на дубли по источнику и подтверждённым реквизитам; SHA использовать только для байтовых дублей.
5. Сотрудник проверяет неоднозначные записи. Неполная иерархия остаётся в staging; фиктивные описи/дела не создаются.
6. Записать предметные таблицы и provenance в транзакции; повтор того же source_key не создаёт второй ресурс.
7. Сформировать языковую редакцию, проверить, опубликовать. Импорт не означает публикацию.
8. Создать задание индексирования, проверить ссылки, количества и ошибки; сохранить отчёт.

Повторная версия источника создаёт новую редакцию, а не затирает историю. Для отката использовать batch/provenance и редакции; не удалять вручную опубликованные записи каскадом. Подписи галереи, контакты отзывов и непроверенный OCR не включаются в ИИ автоматически.

Критерии пробного импорта: повторный запуск идемпотентен; число принятых/отклонённых/ожидающих строк объяснимо; исходные значения восстановимы; неизвестное не превращено в ноль; строки и сущности считаются раздельно.
