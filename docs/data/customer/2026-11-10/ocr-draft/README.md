# Непроверенные OCR-черновики

Шесть текстовых файлов в этой папке — автоматическое распознавание 53 страниц сканов из [архива комплаенс-службы](../originals/Комплаенс%20служба.7z), Tesseract `rus+kaz`, изображения 150 dpi. На каждой странице есть распознанный текст; наиболее короткие страницы с подписями/печатями проверены выборочно визуально. Результаты не редактировались постранично и не являются юридически достоверной копией.

Ошибки возможны в датах, номерах, ФИО, казахских буквах, таблицах, пунктуации, подписях и печатях. Использовать как вспомогательный поиск с обязательной сверкой по оригинальному PDF. Не публиковать и не включать в публичный ИИ без подтверждения ответственных лиц и проверки. В исходниках и черновиках могут встречаться персональные сведения.
