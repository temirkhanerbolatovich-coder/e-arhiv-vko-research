## Границы договорённостей

| Метка | Значение |
|---|---|
| Заказчик | Требование исходного ТЗ; точное содержание — в DOCX |
| Пользователь | Прямое решение пользователя в обсуждении |
| Предложение | Рабочее решение команды; заказчиком не утверждено |
| Открыто | Нужны первичные данные, техническая проверка или согласование |

Сайт исключительно информационный. Нет подачи заявлений и архивных запросов, заказов, платежей, регистрации официальных обращений и оказания услуг. Допустимы отзывы, предложения, пожелания.

**Дизайн не утверждён.** По прямому указанию пользователя макеты, изображения интерфейса, палитры и визуальная концепция в репозиторий не включены. Диаграммы ниже описывают данные и поведение системы, а не внешний вид сайта.

Модель БД — **v0.1 / proposal**. DBML показывает полную целевую логическую структуру, а не необходимость реализовать все модули одновременно. Обязательность функции определяется ТЗ, а не наличием таблицы. Пользовательский кабинет, персональные подписки и избранное не входят в эту версию модели.
