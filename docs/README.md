## Границы договорённостей

| Метка | Значение |
|---|---|
| Заказчик | Требование исходного ТЗ; точное содержание — в DOCX |
| Пользователь | Прямое решение пользователя в обсуждении |
| Предложение | Рабочее решение команды; заказчиком не утверждено |
| Открыто | Нужны первичные данные, техническая проверка или согласование |

Сайт исключительно информационный. Нет подачи заявлений и архивных запросов, заказов, платежей, регистрации официальных обращений и оказания услуг. Допустимы отзывы, предложения, пожелания.

В `frontend/` находится ранее опубликованный интерфейс. Новый локальный редизайн ожидает отдельного согласования и в эту публикацию не входит. Технические диаграммы описывают данные и поведение системы.

Проектная модель в `docs/database/` — **v0.1 / proposal**. Реализованная схема прототипа находится в [backend/src/db/schema.sql](../backend/src/db/schema.sql). DBML показывает полную целевую логическую структуру, а не необходимость реализовать все модули одновременно. Обязательность функции определяется ТЗ, а не наличием таблицы. Пользовательский кабинет, персональные подписки и избранное не входят в эту версию модели.
