# Структура сайта и связь с данными

Все пути ниже — проект новых маршрутов, не существующие страницы. Префикс `/{locale}`: `kk`, `ru`, `en`; пользовательское обозначение языка может быть KZ.

| Раздел | Маршрут-пример | Основные данные |
|---|---|---|
| Главная и чат | `/{locale}` | Публикации, каталог, быстрые переходы, chat_sessions |
| Об архиве | `/{locale}/about` | pages: история, миссия, структура, руководство, отчёты, нормативные ссылки |
| Каталог | `/{locale}/catalog` | funds, inventories, archive_cases, documents, periodical_holdings |
| Карточка материала | `/{locale}/materials/{id}` | resources, опубликованная версия, источники, разрешённые файлы |
| Справочная информация | `/{locale}/guides` | pages типа guide, FAQ |
| Цифровая история региона | `/{locale}/history` | collections, people, places, historical_events |
| Выставки | `/{locale}/exhibitions` | exhibitions, exhibition_items |
| Новости и события | `/{locale}/news` | news, категории, даты |
| Филиалы и контакты | `/{locale}/branches` | branches, контакты, часы, координаты |
| Частые вопросы | `/{locale}/faq` | faq_items |
| Отзывы/предложения | `/{locale}/feedback` | feedback с модерацией |
| Конфиденциальность и права | `/{locale}/privacy`, `/{locale}/copyright` | pages |
| Административная панель | `/admin` | Сотрудники, права, контент, каталог, импорт, модерация, аудит, аналитика |

Главная: чат — главный вход; быстрые переходы к каталогу, выставкам, филиалам; ниже обязательные блоки 5.1: информационный баннер, история в документах, выставки, филиалы с картой, новости, полезная информация, социальные ссылки, подвал. Их окончательная компоновка открыта и не является дизайн-макетом.

Шапка по ТЗ: логотип/официальное название, языки, тема, поиск, каталог, контакты и социальные ссылки. Допустимый способ компактного размещения обсуждается отдельно; незаметное скрытие обязательных функций не считать выполнением требования.

Каталог поддерживает сочетание номера фонда/описи/дела, периода/года, автора/организации, темы, места, ключевых слов, типа, филиала, сортировку, количество результатов, пагинацию и сброс. URL фильтров формирует сервер из проверенных значений.

Карточка: название, шифр и иерархия, датировка, описание/историческая справка, язык оригинала, тип, листы при наличии, место хранения, условия доступа, наличие копии, источники. Просмотрщик: порядок страниц, увеличение, метаданные. Копирование шифра и ссылки не требует аккаунта.

Мобильная версия, клавиатурная навигация, доступность и светлая/тёмная тема обязательны, но их визуальное оформление сейчас не фиксируется. Предпочтения языка/темы можно хранить локально; таблица пользователей для этого не нужна.
