# Концепция: сначала вопрос, затем проверяемый источник

Статус: функциональная концепция команды на основе прямого пожелания пользователя. Визуальный дизайн не утверждён и не включён.

## Основной сценарий

Посетитель открывает сайт без регистрации, видит ИИ-чат и примеры вопросов. Пишет обычными словами, что хочет найти. Помощник ищет по разрешённым опубликованным материалам сайта, даёт короткий ответ с источниками и до трёх наиболее подходящих переходов. Если запрос неоднозначен, задаёт один содержательный уточняющий вопрос.

Пример запроса: «Хочу найти фотографии Усть-Каменогорска в 1960-х». Это пример сценария, не утверждение, что такие фотографии уже есть в доступном наборе.

1. Определить тему, тип материала, место и интервал времени.
2. Учесть проверенные варианты названия города.
3. Совместить точный/текстовый/смысловой поиск и фильтры.
4. Проверить доступ к каждой найденной публикации и каждому использованному файлу.
5. Ответить только по найденным источникам; показать тип, название, период и объяснение релевантности.
6. Перевести пользователя в конкретную карточку, выставку, филиал или каталог с фильтрами.

Кнопка «Открыть каталог самостоятельно» и обычное меню доступны всегда. Недоступность ИИ не блокирует сайт. На странице материала действие «Спросить об этом материале» передаёт его идентификатор; сервер проверяет публикацию, а не доверяет тексту браузера.

## Что делает и чего не делает помощник

Помогает ориентироваться, объясняет архивные термины, находит опубликованные материалы, адреса, расписания, инструкции. Ссылки строит сервер по существующим маршрутам. Указывает отсутствие подтверждения, не придумывает фонды, годы, сканы и наличие документов.

Не принимает заявления, не оформляет услуги, не обещает архивную справку и не запускает операции в административной панели. Не отправляет закрытые документы внешнему провайдеру. Тексты источников не могут менять правила помощника.

## Состояния, которые надо реализовать

| Состояние | Поведение |
|---|---|
| Первый вход | Поле вопроса, несколько понятных примеров, переход в каталог |
| Ответ найден | Краткий ответ и ссылки на конкретные источники |
| Нужна конкретизация | Уточнить период, место или человека, сохранив контекст |
| Нет результата | Честно сказать, предложить изменить запрос или открыть каталог |
| Есть только описание | Не обещать скан; дать карточку со статусом доступа |
| Источник отозван | Не показывать закрытый фрагмент и не давать доступ по старой ссылке |
| Модель недоступна | Показать доступные результаты обычного поиска и сообщение о сбое |
| Смена языка | Сохранить контекст, открыть языковую версию; явно сообщить об отсутствии перевода |
| Возврат со страницы | Восстановить беседу в пределах срока сессии |

## Критерии качества

Ссылки существуют и ведут к заявленному типу материала. Каждый фактический ответ проверяется по источнику. Архивный шифр ищется точно, даже если смысловой поиск ошибся. Результаты тестируются на русском, казахском и английском; сходство векторов не называется вероятностью достоверности.

Метрики для пилота: успешные переходы, вопросы без результатов, оценка полезности, задержка, доля ответов с подтверждаемыми ссылками. Начальные пороги качества устанавливаются после создания проверенного набора вопросов; сейчас измерений нет.
