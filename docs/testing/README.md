# Проверки проекта

## Проверки работающего прототипа

Из корня проекта, Node.js 22:

```sh
npm ci --prefix backend
npm run check --prefix backend
```

Команда запускает проверку TypeScript и серверные тесты. CI в [backend.yml](../../.github/workflows/backend.yml) дополнительно проверяет синтаксис клиентских JavaScript-файлов. Проверки не обращаются к языковой модели.

[Отчёт о проверке опубликованного стенда от 12 ноября](verification-2026-11-12.md) фиксирует версию и границы проверки. Матрица ниже описывает целевую приёмку, а не перечень уже пройденных сценариев.

## Проверки документации

Из корня репозитория (Python 3.12):

```powershell
python tools/docs/build_model.py
python tools/docs/validate_docs.py
```

Для парсинга DBML и перегенерации изображений нужны Node.js и инструменты из `tools/docs/package.json`:

```powershell
npm ci --prefix tools/docs
node tools/docs/render_diagrams.cjs
```

Первый запуск Mermaid CLI может потребовать загрузки Chromium через Puppeteer; доступ к сети нужен только для установки инструментов. Модель и данные не отправляются стороннему сервису диаграмм. В PNG/SVG находятся только проектные поля и связи, без реальных персональных данных.

`build_model.py` формирует DBML, JSON, словарь и Mermaid из одного источника. `validate_docs.py` проверяет ссылки внутри нового пакета, поля/FK/unique, покрытие таблиц диаграммами, полноту извлечённого ТЗ и хеш оригинала. Проверка не запускает сборщик старого сайта и не меняет выгрузку.

## Целевая матрица приёмки

| Область | Проверки поведения |
|---|---|
| Каталог | Родители/FK, одинаковые номера в разных фондах, суффиксы, неполные даты, NULL, исторические названия |
| Импорт | Повтор без дублей, ошибки отдельных строк, отсутствующий родитель/файл, откат, источник/строка, Excel serial dates |
| Публикация | Черновик не меняет публичный материал; язык/версия совпадают; конфликт редакторов; снятие публикации |
| Права | Анонимный/сотрудник/админ другого филиала, подмена ID, прямой URL файла, превью, старые цитаты |
| ИИ | Точный шифр, синонимы/топонимы, три языка, отсутствие результата, неполные сведения, несуществующая ссылка |
| ИИ-безопасность | Инструкции внутри источника, закрытый OCR, устаревший индекс, отзыв доступа между поиском и ответом |
| Файлы | MIME/размер/карантин, отклонённый файл, мастер против превью, порядок страниц, права копий |
| Отказоустойчивость | Модель/карты/индекс недоступны; ручной каталог остаётся доступным; повтор index_job идемпотентен |
| UI | ПК/планшет/телефон, клавиатура/диктор, масштаб, длинный KK-текст, темы, все основные переходы |
| SEO | Переводы/canonical/sitemap, закрытый материал не раскрывается через метаданные/OG |
| Эксплуатация | Восстановление БД и файлов в отдельной среде; истечение сессии; безопасные логи |

Контрольный набор ИИ должен содержать реальные вопросы с заранее подтверждёнными ожидаемыми источниками, вопросы без ответа и запрещённые сценарии. Оценивать корректность ссылок и фактов отдельно от релевантности поиска и времени ответа. Сейчас таких измерений нет.

Фактически выполненное — в [validation-report.md](validation-report.md); таблица выше не является отчётом об успешных тестах приложения.
