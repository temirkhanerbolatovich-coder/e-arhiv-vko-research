Проверено 12 ноября 2026 года. Точный логин действующего участника — **`yeszhannnn`**. Его доступ `Write` подтверждён GitHub API; приглашение принято. Он может читать и менять код, отправлять ветки, создавать и объединять PR и запускать ручной workflow.

GitHub отклонил попытку назначения `Admin` для этого личного репозитория. Полное управление аккаунтом владельца, его секретами и настройками хостинга этим доступом не передаётся. Проект Vercel использует Hobby; отдельное командное управление в панели Vercel требует другого тарифа.

## Изменение сайта

1. Получить актуальную `main` и создать свою рабочую ветку.
2. Внести изменения, проверить сайт локально и выполнить нужные тесты.
3. Отправить ветку в этот репозиторий и открыть PR в `main`.
4. После проверок объединить PR. Production-ветка Vercel — `main`.

## Ручной запуск публикации

Откройте [Actions → Deploy Vercel](https://github.com/temirkhanerbolatovich-coder/e-arhiv-vko-research/actions/workflows/deploy-vercel.yml), нажмите **Run workflow**, выберите **main** и подтвердите запуск. Другие ветки этот workflow не публикует. Эквивалентная команда после входа в GitHub CLI под собственной учётной записью:

```sh
gh workflow run deploy-vercel.yml --ref main --repo temirkhanerbolatovich-coder/e-arhiv-vko-research
```

Workflow вызывает Deploy Hook проекта `e-arhiv-vko-portal`, закреплённый за `main`. Секрет `VERCEL_DEPLOY_HOOK` хранится в GitHub Actions Secrets. URL не публикуется в коде, документации или логах; токен аккаунта Vercel не передаётся.

Успешный запуск Actions подтверждает принятие задания Vercel, а не окончание сборки. Проверяйте Vercel-статус последнего коммита и [основной адрес сайта](https://e-arhiv-vko-portal.vercel.app/). При ошибке запроса запуск помечается неуспешным; автоматического повтора нет, поскольку первый запрос мог быть принят без получения ответа.

## Управление доступом

Hook разрешает только запуск сборки этого проекта из `main`. Он не предоставляет чтение переменных окружения, изменение проекта, доступ к другим проектам или управление аккаунтом Vercel. Права на серверную админку сайта определяются отдельно от GitHub.

Участников с `Write` следует считать доверенными: они могут изменять workflow и код репозитория. Чтобы полностью отозвать доступ к запуску, владелец удаляет участника из репозитория; при необходимости удаляет Deploy Hook в Vercel и секрет GitHub. Если URL hook был раскрыт, его нужно заменить.
