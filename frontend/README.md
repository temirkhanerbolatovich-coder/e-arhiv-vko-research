# Фронтенд Государственного архива ВКО

Клиент информационного портала на HTML, CSS и JavaScript. Модули `api-client.js`, `catalog-live.js`, `admin-live.js` подключают серверные данные и рабочие сценарии; часть экранов сохраняет локальные примеры.

## Запуск вместе с API

Из корня репозитория, Node.js 22:

```sh
npm ci --prefix backend
npm start --prefix backend
```

Откройте `http://127.0.0.1:4173/`. Вход сотрудника — `#/admin/login`; роли и демо-учётки описаны в [README сервера](../backend/README.md). [Контракты интеграции](BACKEND_INTEGRATION.md), [публикация](../docs/deployment/vercel.md).

Список ниже описывает также демонстрационные экраны. Он не означает, что каждый экран полностью подключён к серверу.

## Отдельный просмотр статической вёрстки

Из корня репозитория запустите локальный сервер:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory frontend
```

- [Публичная часть](http://127.0.0.1:4173/) начинается с помощника и обычной навигации.
- [Макет панели сотрудника](http://127.0.0.1:4173/admin-preview.html) открывает модерацию. Остальные экраны доступны в меню.
- Для офлайн-просмотра можно открыть `index.html` или `admin-preview.html` двойным щелчком. Для проверки доступа к буферу обмена и будущего API удобнее HTTP. Внешние источники и карта требуют подключения к сети.

`app.js` маршрутизирует переходы и переключает язык, тему и размер текста. Остальные JS-файлы отвечают за отдельные разделы, а `styles.css` и `portal.css` содержат общие стили. Хэш-маршруты работают при раздаче из обычной статической папки.

## Границы текущей версии

Поиск каталога работает по примерам в браузере. Чат показывает подготовленные сценарии. Отзывы остаются в памяти страницы. В панели сотрудника формы и действия записи отключены. Сайт информирует об архиве и официальных каналах получения услуг. Внутри портала нет подачи заявлений, заказов и оплаты.

Прейскурант и страницы его просмотра подготовлены из файлов заказчика. Герб и флаг взяты с [сайта Акорды](https://www.akorda.kz/ru/state_symbols/about_state_symbols), шрифт Inter приложен с [лицензией](assets/INTER-LICENSE.txt), заголовочный шрифт Literata — с [лицензией OFL](assets/LITERATA-LICENSE.txt). Исторические фотографии в демонстрационной выставке взяты из макета, их атрибуция и права требуют проверки до публичного выпуска. В этой копии на главной используется фон CSS, поэтому исходный дизайн-макет для запуска не нужен. Переводы и справочные данные требуют редакторской проверки архивом.

## Слой оформления и новые блоки (11.11.2026)

- `theme.css` подключается последним и задаёт единые токены (цвета, размеры, скругления, тени, движение) и вид компонентов поверх модулей. Предложение команды, заказчиком не утверждено; откатывается удалением одной строки в `index.html`.
- `home-extras.js` — блоки главной «Машина времени» (фото по десятилетиям, `GET /api/v1/timeline`) и «Памятные даты» (`GET /api/v1/calendar/upcoming`). Без сервера не показываются.
- `voice.js` — «Сказать» (распознавание речи браузера; текст вставляется в поле и не отправляется сам) и «Прослушать» у ответа помощника (синтез речи браузера). Звук на сервер не передаётся; в браузерах без Web Speech API кнопок нет.
