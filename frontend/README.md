# Фронтенд Государственного архива ВКО

Интерфейс информационного портала. HTML, CSS, JavaScript и необходимые ресурсы находятся в этой папке. Для работы с данными и панелью сотрудника запустите сервер из `backend/`.

## Запуск

Из корня репозитория запустите приложение:

```powershell
cd backend
npm ci
npm start
```

Нужен Node.js 22 или новее. Сайт и API доступны по одному адресу. Подробности — в [инструкции сервера](../backend/README.md).

- [Публичная часть](http://127.0.0.1:4173/) начинается с помощника и обычной навигации.
- [Панель сотрудника](http://127.0.0.1:4173/#/admin/login) открывает вход и рабочий стол. Демо-учётные записи описаны в инструкции сервера.
- Для отдельного просмотра интерфейса доступен `admin-preview.html`. Карта и внешние источники требуют подключения к сети.

## Границы текущей версии

При запуске с сервером доступны поиск по загруженным данным, отправка сообщений в гостевую книгу и подключённые операции панели согласно правам сотрудника. При отсутствии API отдельные экраны работают в режиме демонстрации. Без ключа модели помощник использует обычный поиск. Сайт информирует об архиве и официальных каналах получения услуг. Внутри портала нет подачи заявлений, заказов и оплаты.

Прейскурант и страницы его просмотра подготовлены из файлов заказчика. Герб и флаг взяты с [сайта Акорды](https://www.akorda.kz/ru/state_symbols/about_state_symbols), шрифт Inter приложен с [лицензией](assets/INTER-LICENSE.txt), заголовочный шрифт Literata — с [лицензией OFL](assets/LITERATA-LICENSE.txt). Исторические фотографии в демонстрационной выставке взяты из макета, их атрибуция и права требуют проверки до публичного выпуска. В этой копии на главной используется фон CSS, поэтому исходный дизайн-макет для запуска не нужен. Переводы и справочные данные требуют редакторской проверки архивом.

## Слой оформления и новые блоки (11.11.2026)

- `theme.css` подключается последним и задаёт единые токены (цвета, размеры, скругления, тени, движение) и вид компонентов поверх модулей. Предложение команды, заказчиком не утверждено; откатывается удалением одной строки в `index.html`.
- `home-extras.js` — блоки главной «Машина времени» (фото по десятилетиям, `GET /api/v1/timeline`) и «Памятные даты» (`GET /api/v1/calendar/upcoming`). Без сервера не показываются.
- `voice.js` — «Сказать» (распознавание речи браузера; текст вставляется в поле и не отправляется сам) и «Прослушать» у ответа помощника (синтез речи браузера). Звук на сервер не передаётся; в браузерах без Web Speech API кнопок нет.

## Редизайн — первый этап

Главная использует бело-синюю палитру и показывает поле помощника без большого фонового фото. Навигация панели сотрудника сгруппирована по задачам; архивные реквизиты формы записи раскрываются отдельно. Раздел обратной связи называется «Гостевая книга» и отправляет отзывы, предложения, пожелания и сообщения об ошибках через существующий API. В карточках филиалов показаны номера телефонов, если они указаны.

Фотографии зданий, публичная лента и ответы в гостевой книге остаются дальнейшими этапами. API гостевой книги сейчас принимает только категорию и текст, сообщения проходят модерацию. Перед публикацией реальных сообщений необходимо постоянное хранилище и согласование процесса публикации. Права сотрудников по-прежнему проверяются сервером.

### Локальная доработка интерфейса

Рабочий стол панели показывает задачи по правам текущего сотрудника. Каталог приведён к общей палитре, карточки филиалов получили более заметный переход к контактам и маршруту. В гостевой книге добавлены подсказки, счётчик символов и состояния отправки. Для просмотра нужен локальный сервер из инструкции в `backend/README.md`.

Создание записи в панели проходит через выбор материала, описание и проверку перед сохранением черновика. Скан используется для распознавания и не прикрепляется к записи. Сотрудник с правом `content.create` может отправить сохранённый черновик на проверку прямо из формы. В очереди действие также доступно по правам.

### Проверка контактов и модерации

Адреса и телефоны 13 филиалов сверены с видимым листом файла `Адреса и контакты филиалов.xls` заказчика. Почта и часы головного архива взяты из `Контакты.docx`. График филиалов и фотографии нуждаются в подтверждении. Карты с доступными координатами загружаются по запросу посетителя.

В панели очередь модерации позволяет отфильтровать материалы по статусу. Список ограничен 50 записями, а действия определяются сервером. Публичные сообщения и ответы в гостевой книге, сведения об авторе и филиале требуют расширения серверного API и постоянного хранилища.

Поиск фотографий филиалов: в файлах заказчика `История архива.docx`, `Контакты.docx` и `Структура.docx` встроенных изображений не обнаружено. В индексах подписей фотогалереи совпадений с изображениями зданий филиалов не найдено; сами изображения полностью не проверены. Страница Риддерского филиала на Enbek подтверждает существование подразделения, но фотографию здания и права на неё не подтверждает. Нужны изображения от заказчика или другие проверенные источники.

Очередь модерации и административный список сообщений переведены на RU/KK/EN. Тексты ошибок, полученные от сервера, отображаются в исходном виде. Публичный переход в гостевую книгу добавлен в подвал сайта.

Для декоративной полосы `assets/flag-hoist-ornament.svg` и фонового мотива `assets/flag-sun-eagle.svg` использованы фрагменты [вектора флага Казахстана](https://commons.wikimedia.org/wiki/File:Flag_of_Kazakhstan.svg). В шапке и футере повторяется центральный фрагмент орнамента у древка, повёрнутый горизонтально с сохранением пропорций. В панели сотрудника полоса скрыта. Поиск в футере передаёт запрос в каталог с `scope=all` и ищет по опубликованным материалам и страницам в индексе сайта. Административная гостевая книга показывает карточки сообщений и фильтр по статусу, решение и комментарий передаются через существующий API.

Форма создания записи поддерживает RU/KK/EN и сохраняет введённые данные в памяти при переключении языка. После выхода из панели несохранённые данные формы очищаются. Серверные ошибки могут приходить на исходном языке.

### Локальный этап общего оформления

Заголовки выставок, архива памяти, персон, календаря, мест и информационных страниц приведены к общей шкале. Поля новостей и календаря, карточки мест и действия выставок используют малые скругления. Стрелки выпадающих списков имеют единые размер и положение в обеих темах. Заглушка отсутствующего портрета стала компактнее и использует цвета выбранной темы. Главная сохраняет поле помощника у левого края, нижняя мобильная навигация показывает текущий раздел.

В панели сотрудника обновлены оформление входа и строка учётной записи. Для ещё не подключённых экранов показана отдельная пометка, ошибка выхода выводится рядом с кнопкой. При смене маршрута или языка завершение проверки доступа учитывает актуальность экрана. Форма новой записи адаптирована к ширине 320 px, включая поле загрузки файла.

Полное редактирование существующих архивных записей, работа с файлами и управление публикациями через API остаются следующими задачами. Часть публичных материалов формируется из локальных примеров, отдельные подключённые экраны панели и серверные ошибки пока содержат русский текст. Фотографии филиалов, публичная лента гостевой книги и ответы сотрудников требуют дальнейшей работы.

Публичные страницы проверены в браузере на восьми маршрутах при ширине 320 и 1440 px, а также при 720 px с тёмной темой и масштабом текста 200%. Горизонтальная прокрутка и ошибки JavaScript в этих сценариях не обнаружены.

### Каталог и просмотр документов

Каталог показывает состояние серверного поиска без демонстрационного уведомления. Если запрошена недоступная страница, интерфейс открывает доступную страницу и обновляет ссылку. Сервер ограничивает выдачу первой тысячей страниц: на этом пределе посетителю предлагается уточнить поиск или фильтры.

Карточка материала адаптирована для телефона, различает ошибку загрузки и отсутствие записи, сообщает об ошибке копирования и не заменяет страницу устаревшим ответом при переходе. Кнопки и поля просмотрщика PDF адаптированы к узкому экрану. Сейчас просмотрщик работает с двумя PDF прейскуранта; подключение произвольных файлов из архивных карточек требует отдельной интеграции.

### Чат и информационные разделы

В чате примеры демонстрационных ситуаций свёрнуты. При проверке доступности сервера подсказка под полем обновляется, а при получении ответа сохраняются набираемый следующий вопрос и положение курсора. Ошибка копирования ответа отображается пользователю.

На странице структуры длинные названия подразделений занимают всю ширину карточек. На обложке выставки улучшен контраст текста, а окно изображения адаптировано к узкому экрану. Фотографии выставки и отдельные сведения об архиве требуют подтверждения заказчика.

### Филиалы и гостевая книга

При позднем ответе с координатами раздел филиалов сохраняет открытый просмотр карты и фокус выбранной карточки. Результат геолокации не заменяет филиал, выбранный вручную после начала определения местоположения.

Гостевая книга сохраняет черновик и состояние отправки при смене языка и переходах до перезагрузки страницы. Форма показывает подсказку рядом с полем и различает ошибку проверки, ограничение частоты и отсутствие подтверждения от сервера. После ответа `{ ok: true }` очищается отправленный текст, если посетитель не изменил его за время запроса. При неопределённой сетевой ошибке повторная отправка может создать дубликат, поскольку сервер пока не поддерживает ключи идемпотентности.

В административной гостевой книге причина отклонения вводится прямо под сообщением. При ошибке текст остаётся в форме, а выбранный фильтр сохраняется в пределах сеанса при смене языка. Если решение сохранилось, а список не обновился, кнопка повтора запрашивает только список. То же поведение предусмотрено в очереди проверки архивных материалов.
### Фильтры каталога и архивные элементы

Кнопка «Фильтры» рядом с поиском открывает диалог. В окне можно сбросить или применить условия. Закрытие без применения возвращает предыдущий набор фильтров. Активные условия видны под строкой поиска, их можно снять отдельно. Прежние параметры поиска и ссылка с `advanced=1` поддерживаются.

Из серверной карточки ссылка «К результатам поиска» возвращает запрос, применённые фильтры, сортировку и страницу. При копировании ссылки передаётся только адрес записи. Для открытых записей с доступной копией есть действие «Открыть цифровую копию», использующее существующий `GET /api/v1/resources/:id/file`. Локальные примеры без API используют свои прежние карточки.

### Филиалы и источники

В карточках филиалов ссылки на маршруты находятся сразу после адреса, телефона и графика. Телефон отображается по исходному документу, а ссылка для звонка использует формат `+7` для номеров с префиксом `8`.

Названия подразделений и поиск по ним доступны на RU/KK/EN. Адреса, телефоны, почта и графики загружаются из `GET /api/v1/branches`. Без API открывается сохранённый справочник. Для головного архива часы учреждения и читального зала показаны отдельно. Данные из начального заполнения сверяются с `Контакты.docx`; неподтверждённый шаблон графика филиалов отображается как «Уточняется». Сторонняя карточка головного архива показывает другое время закрытия, поэтому перед публикацией следует сверить расписание с учреждением.

В [редакторе филиалов](http://127.0.0.1:4173/#/admin/branch-editor) сотрудник с правом `branches.edit` меняет адрес, телефон, почту, график и видимость отметки. Администратор филиала редактирует своё подразделение. При вводе нового адреса отметка по умолчанию скрывается, пока сотрудник не включит её вручную. Если основной график и график читального зала различаются, второй можно ввести в отдельной строке после «Читальный зал:». Успех показывается после подтверждения сервера. При сбое несохранённые правки остаются в форме. Изменения доступны в публичном справочнике, а контакты головного архива также в подвале, на главной и справочных страницах.

Маршрут и расстояние по прямой используют только точки уровня здания. Для точек уровня улицы или населённого пункта внешняя карта открывается по адресу из карточки. В Катон-Карагае геокодер сопоставил дом 19, тогда как в справочнике указан 19/1, поэтому маршрут тоже открывается по адресу. Поиск ближайшего подразделения сохраняет выбранный тип, а расстояния рассчитаны для подразделений, у которых есть координаты здания.

Для локального просмотра здания головного архива добавлен `assets/archive-building-preview.jpg`. [Публикация YK-news](https://yk-news.kz/news/v-ust-kamenogorske-gosudarstvennyy-arhiv-provodit-den-otkrytyh-dverey-64048) указывает, что фото взято с сайта архива. Перед публичным размещением подтвердить разрешение на использование снимка. Для головного архива и филиала по личному составу на Потанина, 12/2 добавлены ссылки на панорамы. Для остальных подразделений фотографии зданий пока не подтверждены.

Внешние фотогалереи привязаны к [головному архиву](https://yandex.kz/maps/ru/org/shyghys_qazaqstan_oblysynyng_memlekettik_muraghaty/118215067870/gallery/?lang=ru), [филиалу по личному составу](https://yandex.kz/maps/ru/org/shyghys_qazaqstan_oblysy_memlekettik_muraghatynyng_filialy/137746419812/gallery/?lang=ru) и [филиалу Алтай](https://yandex.kz/maps/ru/org/shyghys_qazaqstan_oblysynyng_memlekettik_muraghaty_altay_filialy/244165745020/gallery/?lang=ru). Адреса карточек совпадают с документами заказчика. Снимки из этих галерей открываются на стороне источника.

### Архивные акценты

В шапке, подвале и значке вкладки используется эмблема архива из сохранённой выгрузки [оригинального сайта](http://e-arhiv.vko.gov.kz/Content/Images/lang/Logo_ru.png). Русская и казахская версии исходного файла совпадают. Формулировки полного названия взяты с главной прежнего сайта для RU/KK, для EN использован перевод. Архивный логотип можно заменить исходником заказчика, обновив `assets/archive-logo.png`.

В `theme.css` добавлены бумажные оттенки для карточек материалов и подписей в «Машине времени», выделение активной навигации и книжный мотив справа от помощника на широком экране при обычном размере текста. Декор создаётся средствами CSS, а новые эффекты отключаются при включённом уменьшении движения.

Под публичной шапкой расположена строка поиска, закрепляющаяся при прокрутке. Она использует тот же поиск по опубликованным материалам, что и форма в футере. Панель сотрудника использует свою навигацию.

### Лента новостей, выставки и опубликованный каталог

- [Новости](http://127.0.0.1:4173/#/section/news) открывают опубликованную ленту на RU/KK. Интерфейс EN показывает русскоязычные оригиналы. Поиск по заголовку, страница выдачи и возврат из публикации сохраняются в ссылке. Вкладка «Подборка» сохраняет категории и сортировку для трёх материалов по госисточникам. При недоступности API открывается эта подборка.
- [Выставки и фотоальбомы](http://127.0.0.1:4173/#/section/exhibitions) открывают онлайн-выставку и шесть альбомов с обложками и ссылками на [фотогалерею прежнего сайта](http://e-arhiv.vko.gov.kz/ru/SiteGallery). Названия и число снимков сверены с индексом `datasets/gallery/albums.json`. На главной карточки «История в документах» показывают те же подписи и ведут к экспонатам.
- [Опубликованный каталог в панели](http://127.0.0.1:4173/#/admin/catalogue) показывает реальные записи из API с поиском, фильтром по типу и пагинацией. Карточка открывается в новой вкладке, черновики доступны через очередь проверки. Таблицы журнала, сотрудников, ролей и отчёта импорта прокручиваются внутри панели на узких экранах.

### Локальные редакторы и файлы — 12.11.2026

Из опубликованного каталога доступно действие «Подготовить изменения»: редактирование описания и реквизитов, проверка лет, сравнение с оригиналом и скачивание черновика JSON. Опубликованная карточка не меняется.

Раздел файлов принимает PDF/JPEG/PNG/TIFF в локальную очередь, проверяет формат и лимиты, позволяет добавить подпись, привязать скан к черновику, посмотреть изображение и скачать реестр. Загрузки на сервер нет.

В публикациях доступны создание локального материала, поиск по заголовку и типу, предпросмотр, RU/KK/EN, проверка заполнения оригинала и экспорт. Редактор переводов показывает оригинал и перевод рядом, сохраняет ввод при переключении языка и снимает отметку проверки при изменении текста.

Черновики и файлы сохраняются при переходах внутри вкладки, очищаются при перезагрузке или выходе. Подробные сценарии, ограничения, JSON-форматы и команды браузерных проверок — в [инструкции локального рабочего места](LOCAL_STAFF_WORKFLOWS.md).
